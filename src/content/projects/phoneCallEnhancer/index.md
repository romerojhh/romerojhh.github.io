* Developed an android application that enhance a VoIP phone call audio with the help of machine learning model by Picovoice to reduce background noises as well as real time Speech-To-Text
* Developed an automatic volume normalizer that automatically increase or decrease input audio volume to the receiver
* Utilized Websocket as the underlying technology for our Golang server
* Implemented audio wave visualizer from scratch that process the audio data on the fly
* Worked extensively with multi-threading and computer network programming
* Implemented conversational style chat bubbles between caller and receiver for Speech-To-Text to improve usability and accessibility
