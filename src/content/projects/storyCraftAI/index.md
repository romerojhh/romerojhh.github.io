* Designed a seamless and accessible AI-assisted storytelling SMS chatbot that anyone can use by simply texting a U.S. phone number
* Utilized Twilio as the technology to enable programmable text message
* Utilized Fixie.ai for artificial intellegence agent that specialize in on-the-fly storytelling capability
* Node.JS used for serverless REST API call
* Liquid Template Language used for manipulating variables in serverless environment
